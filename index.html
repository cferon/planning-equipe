Connexion coach

Connectez-vous avec l’adresse e-mail autorisée par la personne qui gère le planning. Vous recevrez un code de connexion à 6 chiffres.



Gestion des coachs

Ajoutez, renommez ou retirez un coach. Ces changements seront partagés avec toute l’équipe.

La dernière visite est enregistrée à chaque ouverture du planning après connexion.

Gérer les cours

Ajoutez un cours ici. Dans le planning ci-dessous, utilisez ✎ pour modifier un cours ou × pour le supprimer. Les disponibilités et l’attribution des coachs ne sont pas affichées dans ce mode.

Choisissez votre prénom puis indiquez votre disponibilité.

Bilan des cours

Choisissez une période pour compter les cours attribués. L’export PDF passe par la fenêtre d’impression du navigateur.

Effacer les disponibilités et affectations

Les cours récurrents et les exceptions (annulations, changements de nom ou d’horaire) seront conservés. Cette opération retire les disponibilités et les affectations des mois sélectionnés ; les anciens bilans ne pourront ensuite plus être recalculés à partir de ces données.
