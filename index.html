Connexion coach

Connectez-vous avec l’adresse e-mail autorisée par la personne qui gère le planning. Vous recevrez un lien de connexion.


Gestion des coachs

Ajoutez, renommez ou retirez un coach. Ces changements seront partagés avec toute l’équipe.

Gérer les cours

Pour supprimer une occurrence, utilisez × sur le cours. Pour un cours récurrent, vous pourrez supprimer uniquement cette occurrence ou celle-ci et les suivantes. Ouvrez « Gérer les cours » pour modifier ou supprimer un cours depuis les boutons affichés sur chaque séance.
